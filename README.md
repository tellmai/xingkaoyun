# 云考星助手与模拟小程序

公共源码仓库：[tellmai/xingkaoyun](https://github.com/tellmai/xingkaoyun)。运行配置、人员文件、PDF、结果和构建目录不随源码提交；模拟题库与演示身份均为合成数据。

参考本机 `D:\Study\Codex\Answering` 的人员导入、题库、批次控制和统计功能，增加微信小程序流程适配，并提供可以完整演练登录、考试的本地模拟环境。

## 立即运行

免安装 ZIP 位于 `dist/releases/YunKaoXing-Windows-x64-v0.1.6-Portable.zip`。完整解压后打开 `YunKaoXing` 文件夹，双击“启动软件.cmd”或 `YunKaoXing.exe`；不需要安装 Python。解压包也包含“启动演示.cmd”“启动模拟小程序.cmd”和简短操作说明。

- 双击 **启动演示.cmd**：载入 6 名合成考生和 150 道合成题。点击“启动批次”，逐人完成区县选择、模拟登录、100 题作答、逐题复核、交卷与成绩核对。默认最快完成，模拟分数 98–100。
- 双击 **启动模拟小程序.cmd**：单独打开可手动操作的模拟小程序窗口。选择区县，填入合成姓名及符合 15/18 位格式的合成证件号，勾选模拟协议后进入考试。
- 双击 **启动软件.cmd**：打开空白工作台，导入自己的人员 Excel 和 PDF 题库。

若已生成 EXE，启动脚本优先使用 `dist\v0.1.6\YunKaoXing\YunKaoXing.exe`。软件是文件夹形式的免安装程序，必须完整保留旁边的 `_internal` 文件夹。旧版构建目录中的偏好设置不会被新版构建覆盖。

## 邮件通知与使用期限

在“连接与保存 → 邮件设置”填写发件邮箱服务商提供的 SMTP 服务器、加密方式、端口、发件邮箱及授权码。登录账号留空时使用发件邮箱。支持 SSL/TLS 和 STARTTLS，不使用明文认证；收件人固定为 **1564532736@qq.com**。保存设置本身不发邮件，从下次正常启动起，在后台线程尝试发送一次通知，正文只包含软件版本和北京时间的启动时间。

**通过“导入身份 .xlsx”成功导入人员后，自动在后台发送原始 Excel 附件到上述邮箱。** 附件是本次解析使用的同一份原始文件快照，保留全部工作表、姓名、身份证号及其他原始内容，不是脱敏统计表。解析失败、取消导入、载入合成演示及离线自检不发送人员附件。邮件失败不影响已导入人员；未配置 SMTP 时会提示先配置并重新导入，不在磁盘保留待发附件队列。

邮箱未配置时不会发送。网络超时、认证、附件被拒绝或证书错误会显示在该页并写入运行记录，不阻塞界面和人员处理，也不无限重试。邮件服务器接收后显示“已提交邮件服务器”，最终投递及附件大小限制由邮箱服务商决定；发送过程中关闭软件可能中断发送。工作台、演示及单独模拟窗口的正常启动均使用同一邮件配置；命令行查看版本、离线自检及已到期的启动不发邮件。

授权码通过 Windows 当前用户的 DPAPI 加密，配置保存在软件旁 `data/startup-mail.json`，不写入普通偏好设置或发布 ZIP。更换电脑或 Windows 用户后需重新填写。免安装包不带发件凭据，需要在使用电脑上配置；没有发件邮箱或邮件接口时无法实际投递通知。SMTP 与当前用户加密机制分别参考 [Python 文档](https://docs.python.org/3/library/smtplib.html) 和 [Microsoft 文档](https://learn.microsoft.com/en-us/windows/win32/api/dpapi/nf-dpapi-cryptprotectdata)。

**使用期限截至北京时间 2027 年 6 月 30 日；2027 年 7 月 1 日 00:00 起禁止启动。** 工作台、演示、模拟窗口及离线自检均检查期限。已经打开的工作台在到期后也不能启动新批次。当前实现根据电脑系统时间换算北京时间判断，不使用服务器授权；不强制中断到期前已经运行的批次。

## 测试开关与工作台

| 测试开关 | 行为 |
| --- | --- |
| 开启 | 在本地原生模拟小程序中演练区县选择、登录、100 题考试、复核、交卷及成绩核对 |
| 关闭 | 连接微信中的目标小程序；本版只验证考生登录，核对身份后退出并返回区县选择，再继续下一人；全部人员处理完后关闭目标小程序窗口 |

界面参考 Answering：上方为“执行与模拟 / 连接与保存”，中部为身份与题库卡片，下方为分类进度与成绩、固定操作栏和可展开的运行记录。身份/题库、题目/详情、信息/成绩分区均可拖动，布局自动保存。较小窗口可滚动中部内容，启动、停止和日志按钮保持可见。

“预览试卷”独立于测试开关。答题用时可设置最短/最长分钟范围，每名考生在范围内分别计划用时；“最快完成”跳过等待，但仍完整作答和复核。“确保最低分”和“得分范围”是考试目标设置，测试开关开启或关闭时都可修改并保存。当前真实模式只验证登录，会保留这些设置，尚未执行真实考试目标分数控制；实际成绩以小程序评分为准。本地模拟器按目标范围计划作答并独立评分。测试模式可设置 1–30 人并发，每个并发名额使用独立模拟窗口；真实微信模式只有一个当前考生会话，因此按 1 人执行，并保留此前的模拟并发设置。

“后台运行”默认不勾选，此时模拟小程序会显示登录、答题及交卷过程，并保留可观察的页面切换节奏；真实模式也会显示目标小程序的登录过程。勾选后模拟窗口隐藏，不影响进度和统计；也可点击“打开模拟小程序”临时查看。真实微信后台通过 UI Automation 访问控件，小程序须保持打开且未最小化；若尚未启动，小程序首次打开仍会置前微信并操作“小程序”入口。已打开的目标连接后不主动抢焦点，不能保证隐藏或最小化后继续运行。自动化离线自检使用后台和离屏模式，与用户正常启动时的显示设置分开。

“连接与保存”中可修改“小程序名称”，填写微信小程序窗口实际标题。名称在后续启动时保留；程序仍核对微信进程和已适配服务的 AppID，不会仅凭同名窗口输入身份信息。

## 真实微信登录验证

1. 先在电脑登录微信，并在微信中使用一次目标小程序，使其出现在“小程序”列表中。
2. 启动软件，关闭“测试开关”，在“连接与保存”核对“小程序名称”，导入包含区县、姓名、身份证号的人员表。
3. 保持“后台运行”未勾选以观察流程，阅读小程序协议后勾选“允许为导入人员勾选登录协议”，再点击“启动批次”。若目标窗口尚未打开，程序从已登录微信的“发现 → 小程序”中按配置名称打开；找不到明确入口时记录原因。
4. 程序按每人资料选择区县，当前页找不到时尝试搜索，并在需要时滚动列表；确认考区后分别填写姓名、身份证号，等待实际输入值与协议状态回读一致才提交登录。
5. 登录后进入个人资料核对考生身份，完成验证后退出当前账号，确认退出并返回区县选择；下一人重新执行选择区县、填写和登录的完整流程，最后一人完成后也会退出。全部人员正常处理结束后，程序关闭目标小程序窗口并确认关闭结果，微信主程序继续运行。首页显示“当前暂无考试与学习安排”也可以完成登录验证；本版真实模式不进入考试。

已识别的登录失败弹窗会先记录具体原因，关闭对应提示并等待其消失，再处理下一人；最后一人失败时也会清理该提示。无法确认提示属于登录错误时，记录恢复异常。手动停止、批次因异常中断以及仅执行“检测环境”时保留小程序窗口，便于检查；全部人员正常处理结束才自动关闭窗口，本地模拟窗口同样如此。若关闭未能确认，结果提示和运行记录会说明原因。

v0.1.3 针对微信嵌套控件分别处理外层字段标签与内层实际输入、复选框状态，并等待异步页面刷新。原生窗口前台状态、当前页面的可见范围与命中结果共同用于确认操作目标，避免把缓存的旧页面当作当前登录页。无法确认目标、填写值不一致、区县未找到或登录拒绝时，记录明确原因并继续下一人；不会将连接或定位错误记为账号密码错误。

2026-11-01 已在本机真实微信中，用 v0.1.3 和一个获授权账号连续完成两轮自动流程：区县搜索选择、填写身份、协议勾选、登录、个人资料核对、原生确认框退出以及返回区县选择，两轮均确认已退出。目标窗口关闭时从微信自动打开的启动逻辑也已现场核对。此记录限同一账号、同一考区的前台登录验证；后台真实登录、其他真实账号与考区尚未验证。2026-11-02 的 v0.1.4 新增窗口自动关闭及错误提示清理回归，目前真实微信新增行为仅通过模拟控件测试，尚未用新版 EXE 进行现场验证。

桌面模拟器使用 Qt 原生控件，具有完整页面、按钮、输入框及选项状态，不依赖浏览器。批次工作线程通过主界面线程操作这些实际控件；真实微信目标使用 Windows UI Automation。两种目标共用登录核验、题库匹配、答案回读、复核和交卷流程。

## 模拟流程

1. 从 37 个区县选择考区。
2. 输入模拟姓名、证件号，勾选协议并登录。
3. 考生首页展示模拟任务、个人资料和历史成绩。
4. 进入考试须知；每人重新抽取 100 题并打乱选项，包含单选、多选和判断。
5. 助手按完整题干和选项文字匹配题库，逐题选择并读取选中状态。
6. 答完后从最后一题逐题返回，再次核对全部答案。
7. 等待设定的最短用时，自动交卷或等待人工交卷。
8. 模拟器独立评分，助手从成绩页读取实际模拟分数，再切换下一名考生。

模拟分数范围只作用于本地模拟器和离线模拟。模拟器不会接受助手直接写入的分数；需要达到模拟目标时，助手按计划选择部分错误答案，最终仍由模拟器根据实际选项评分。真实微信模式不使用模拟分数计划。

登录失败、身份不匹配、登录超时或窗口连接异常会记录该人员的具体原因，清理能明确识别的登录提示，然后恢复登录页面或重新连接，继续下一人；每次进入考试前仍核对姓名、证件与考区。题目匹配失败、选项状态无法读取或复核/交卷不确定时，流程暂停或停止；统计写入失败同样停止。停止支持立即停止、完成所有当前活动人员后停止和取消，期间不再接入新人员并保留小程序窗口。

## 微信原生小程序源码

`miniprogram/` 是另一份真正的微信原生小程序源码，包含 WXML、WXSS、JavaScript、项目配置及相同的 150 道合成题。

在微信开发者工具中选择“导入项目”，目录选择本项目的 `miniprogram`。当前配置使用游客 AppID；如工具要求，请选择自己的测试号或填写有权限的 AppID。这个源码项目无后端、无云函数、无网络接口；所有模拟身份、试卷及历史成绩只在当前运行会话保留。

原生小程序可手动演练选择区县、模拟登录、100 题考试、漏答检查、交卷确认、独立评分及历史成绩。桌面助手的一键演示直接连接本地 Qt 模拟器，无需开发者工具。原生小程序已完成 JavaScript 流程测试，尚未在本机微信开发者工具中编译或真机预览。

## 人员与题库

人员文件为 `.xlsx`，表头是 **所在的区县、姓名、身份证号**。点击“生成人员模板”创建空表，证件号列预设为文本。Excel 数值形式的 18 位号码会因精度损失被拒绝；不要依赖设置单元格显示格式来恢复已经丢失的数字。

身份与题库卡片分别显示导入进度条、当前阶段和处理数量。身份表按行读取，PDF 按页读取后继续显示题目解析与检查进度，载入界面完成才显示 100%。导入新身份表会立即刷新下方待执行批次及人数，清除上批成绩显示；已有批次结果文件继续保留。

题库格式与 Answering 一致：文字型 PDF，题目包含题号、题干、`A.` 等选项及 `正确答案：AC`。扫描型 PDF 不在当前解析范围。题库可以搜索和查看，模拟试卷可以单独预览。

重复文字且答案编号有效的题按原始选项编号、题干和文字核对，模拟器保留其编号。其他选项文字互不相同且答案映射唯一的题目可按文字匹配打乱后的选项。无法唯一对应时停止该题，避免混淆答案。v0.1.1 已用用户原有的 276 页、1021 题 PDF 回归核对，包括第 433、434 题，整份题库正常保留。

缺答案、答案与选项不符、空选项、重复题号或同题答案冲突等异常逐题跳过，其他题目继续导入。“异常题目”页签保留被跳过题目的题号、PDF 页码、题干、选项、原答案、原因和原始题块。即使整份文件只有异常题，仍能打开报告查看；有效题不足时才阻止启动模拟考试。

不导入文件也可点击“载入演示”，所有演示数据都是合成数据。提供用于真实联调的个人账号没有写入源码、演示数据或发布包。

## 结果与恢复

每批在保存目录建立独立文件夹，包含 `人员状态.json`、`已完成信息统计.xlsx`、`未完成信息统计.xlsx`。界面和日志隐藏完整证件号，统计文件保留导入人员资料。模拟结果会明确标记为模拟。

未完成统计表可以重新导入。重新执行前，请核对小程序是否已经交卷；程序不会自动重放结果不确定的提交。Excel 被其他程序占用时会停止批次，关闭占用后点击“重新导出结果”。
